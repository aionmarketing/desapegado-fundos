# Kit para o novo chat de fundos

1. No novo chat/projeto, cole o conteúdo de `PROMPT-NOVO-CHAT.md`.
2. Anexe os arquivos da pasta `referencias/` (ou disponibilize esta pasta inteira se o chat tiver acesso local).
3. O dono escolhe um ambiente e descreve o que quer mudar; a IA entrega fundo isolado e composição com produtos, nos dois formatos.

Os produtos da captura são referência de composição. Não foram exportadas fotos privadas do catálogo para este kit. No mesmo computador, o novo chat pode consultar a prévia local sob as regras do checkout; em outro ambiente, forneça algumas fotos reais/recortes para montar as provas.

Este kit é um recorte visual datado de 04/11/2026, não uma cópia do código, da conversa ou do estado operacional. O prompt não foi executado aqui; nenhuma página foi alterada nesta preparação. Origem, bytes e hashes das cópias em `manifest.json`.
